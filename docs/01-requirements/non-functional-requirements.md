# 非功能需求

## 1. 一致性与正确性

| 编号 | 需求 | 验收方式 | 优先级 |
| --- | --- | --- | --- |
| NFR-01 | 同一行程只能发放一次积分 | 唯一约束与重复提交测试 | P0 |
| NFR-02 | 积分余额不得为负数 | 边界和并发兑换测试 | P0 |
| NFR-03 | 商品库存不得为负数或超卖 | 并发兑换测试 | P0 |
| NFR-04 | 订单、积分流水和库存变更保持原子性 | 故障注入和事务回滚测试 | P0 |
| NFR-05 | 历史行程的计算结果不因规则更新而改变 | 规则版本切换测试 | P0 |

## 2. 可追溯性与审计

| 编号 | 需求 | 说明 | 优先级 |
| --- | --- | --- | --- |
| NFR-06 | 每笔积分变动都有唯一流水记录 | 包含业务类型、业务编号和变动后余额 | P0 |
| NFR-07 | 行程保存使用的规则版本和因子快照 | 支持重新解释历史计算 | P0 |
| NFR-08 | 规则和订单状态变更记录操作审计信息 | 操作人、时间、旧值、新值和原因 | P1 |

## 3. 安全与权限

| 编号 | 需求 | 说明 | 优先级 |
| --- | --- | --- | --- |
| NFR-09 | 密码必须加盐哈希保存 | 禁止明文或可逆加密 | P0 |
| NFR-10 | 所有业务接口必须校验身份和角色 | 用户、商户、运营管理员最小权限 | P0 |
| NFR-11 | 用户只能访问本人行程、积分和订单 | 防止水平越权 | P0 |
| NFR-12 | 日志不得记录密码、令牌和完整敏感信息 | 降低泄露风险 | P0 |

## 4. 可用性与易用性

| 编号 | 需求 | 验收方式 | 优先级 |
| --- | --- | --- | --- |
| NFR-13 | 核心流程提供明确的中文提示和错误原因 | 页面走查与功能测试 | P1 |
| NFR-14 | 减排结果显示完整计算依据 | 用户能看到里程、因子和结果 | P1 |
| NFR-15 | 兑换失败后不改变账户与库存状态 | 功能测试和数据库核对 | P0 |

## 5. 性能与容量

课程演示环境暂定以下目标，最终数值由指导教师要求和部署环境调整：

| 编号 | 需求 | 初始目标 | 优先级 |
| --- | --- | --- | --- |
| NFR-16 | 普通查询接口响应 | 本地演示数据量下不超过 1 秒 | P1 |
| NFR-17 | 核心写入接口响应 | 本地演示数据量下不超过 2 秒 | P1 |
| NFR-18 | 并发兑换正确性 | 至少验证 20 个并发请求下不超卖、不透支 | P1 |

性能目标只适用于课程原型，不能当作生产容量承诺。

## 6. 可维护性与可部署性

| 编号 | 需求 | 说明 | 优先级 |
| --- | --- | --- | --- |
| NFR-19 | 业务模块边界清晰 | 账户、出行、积分、商城、运营分别组织 | P1 |
| NFR-20 | 数据库变更可重复执行 | 提供初始化脚本和迁移说明 | P1 |
| NFR-21 | 系统可以重复部署 | 提供明确的环境变量和启动步骤 | P1 |
| NFR-22 | 关键业务规则具备自动化测试 | 碳核算、幂等、余额和库存覆盖 P0 场景 | P0 |

## 7. 合规与表述

| 编号 | 需求 | 说明 | 优先级 |
| --- | --- | --- | --- |
| NFR-23 | 页面和报告明确标注模拟数据与模拟核算 | 不宣称具有官方认证效力 | P0 |
| NFR-24 | 积分不可提现、不可转让 | 避免被误解为金融资产或碳资产 | P0 |
| NFR-25 | 引用外部排放因子时记录来源和版本 | 无法核实时标注为课程假设 | P1 |
